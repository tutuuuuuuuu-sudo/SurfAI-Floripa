# Surf AI Floripa

> Este arquivo descrevia uma versão inicial/protótipo do app (dados simulados, sem
> autenticação, pagamento, IA ou push). Essa versão não existe mais — o app de produção
> usa dados reais (Open-Meteo, StormGlass, Windy), Supabase, Mercado Pago e Gemini.
>
> A documentação atual e mantida do projeto vive em **[`CLAUDE.md`](../CLAUDE.md)**, na
> raiz do repositório — arquitetura, regras de negócio, banco de dados, variáveis de
> ambiente e checklist de mudanças ficam todos lá, atualizados a cada sessão de trabalho.
> Consulte este arquivo se precisar do histórico de como o app começou.
